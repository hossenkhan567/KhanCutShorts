# ✂️ KhanCutShorts

Upload a video or paste a link, pick a ratio (9:16, 4:5, 1:1 ...) and download a smart-cropped version.

Built on [AutoCrop-Vertical](https://github.com/kamilstanuch/AutoCrop-Vertical) (YOLOv8 + FFmpeg).
